## Post-V1 job coordination

- Durable, restart-resumable ingestion jobs and multi-worker coordination are deferred. V1 uses one local backend process and one ingestion worker; in-progress jobs are marked interrupted after restart and can be retried by submitting ingestion again.

## Post-V1 environment identity

- V1 environment identity includes the absolute Python executable and `sys.path`, so relocating the repository or interpreter can intentionally change future environment and snapshot IDs. Path-independent environment identity and any explicit migration/aliasing strategy are deferred. Historical environment IDs, snapshot IDs, provenance, runtime observations, evaluations, and evidence must remain unchanged and explicitly scoped; future work must not silently alias or combine records from distinct identities.

## Post-V1 runtime instrumentation hardening

- Adversarially trustworthy external tracing is deferred. V1 keeps useful in-process pytest observations under the documented ordinary, non-adversarial OSS repository assumption. These observations describe instrumentation output for a specific run; they are not authenticated structural facts, and they never create deterministic graph relationships. The isolated Docker host-protection controls remain required.
